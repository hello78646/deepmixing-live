# Deepmixing · 全民混音（公开试混）

双轨交叉淡化、试听与 16-bit 立体声 WAV 导出。文件只在当前浏览器里解码和渲染；页面没有注册、遥测、音频上传或远程 API。刷新后需要重新选择音频。

这是一份独立网页，不包含完整本地桌面工作台、Agent、自动对拍或分轨。演示音频由代码合成。通过任意静态服务器打开 `index.html`，或访问本仓库的 GitHub Pages。

## 零氪开场语音

页面随附授权音色合成的固定开场（`lingke-opening-v1.mp3`），页面、语音尾部和 MP3 元数据均标注为 AI 合成语音。不提供在线合成，也不包含参考录音、模型或本机配置。

打开页面即尝试有声播放；浏览器拦截时点「播放零氪开场」。可以停止或重播，开始试听混音时开场会自动让出声音。将 `index.html` 的 `#opening-voice` 按钮的 `data-src` 留空可关闭开场。
