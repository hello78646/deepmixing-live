# Deepmixing · 全民混音（公开试混）

双轨交叉淡化、试听与 16-bit 立体声 WAV 导出。文件只在当前浏览器里解码和渲染；页面没有注册、遥测、音频上传或远程 API。刷新后需要重新选择音频。

这是一份独立网页，不包含完整本地桌面工作台、Agent、自动对拍或分轨。演示音频由代码合成。通过任意静态服务器打开 `index.html`，或访问本仓库的 GitHub Pages。


## 零氪开场语音

加入有权公开使用的成品 MP3 后，在 `index.html` 的 `#opening-voice` 按钮上设置 `data-src="./lingke-opening.mp3"`。不要提交参考录音、语音模型或本机配置。建议试混版台词：「我是零氪。挑两段音乐，调一下交接，听听它们接在一起是什么样。」

配置后，打开页面即尝试有声播放；浏览器拦截时可以直接点「播放零氪开场」。开场可随时停止，播放混音时会让出声音。未配置音频时不显示按钮，也不会请求音频。
